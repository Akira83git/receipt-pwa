# レシート色分け PWA

iPhoneでレシートを撮影し、OCRで抽出した商品行を4色に分けて合計する最小試作です。読み取り金額は手動修正でき、色別合計はリアルタイムに更新されます。

## 最初の実装ステップ：パソコンで起動する

このフォルダでローカルWebサーバーを起動し、ブラウザーで画面が表示されることだけ確認します。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。ファイルを直接ダブルクリックするとPWAのオフライン機能が動かないため、Webサーバー経由で開いてください。

初回のOCR実行には通信が必要です。一度読み込んだOCR資材はブラウザーに保存され、以後のオフライン利用に回されます。
